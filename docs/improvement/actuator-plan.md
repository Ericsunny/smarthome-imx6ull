# 执行器恢复：场景与验证计划

基准：35eb1a0，日期：2026-11-17。上一阶段保留了驱动但移出了执行器应用。本轮恢复 SG90 舵机和 28BYJ48/ULN2003 步进电机；摄像头及远端考勤仍不参与主程序。

## 硬件与来源

SG90 已有 PWM3、50 Hz 角度控制驱动；28BYJ48 已有 GPIO 四相八拍与阻塞 ioctl。它不是另一台 PWM 直流电机。本地 TB6612 文件是其他内核环境的参考代码，不纳入本轮系统，也不据此声明已有 TB6612 实测。

## 使用场景

固定室内空间的环境辅助控制与离场布防：

- 温湿度超限时请求 SG90 打开小风门，恢复到回差范围后请求关闭。SG90 用于挡板角度，不再把来回摆动的舵机描述成真正的风扇。
- 光照低于 30 的估算值请求关闭采光/隐私帘，高于 80 请求打开；中间区间保持。用途是日间采光、暗时隐私，不能称为已验证防晒策略。光照传感器须朝窗侧且不被帘体明显遮挡；否则不能直接套用。
- PIR 仅用于人工布防后的活动提醒，不从持续低电平推断无人，不参与风门或帘体动作。

前两项是机构应用假设。代码和模拟可验证命令规则，实际机构行程、通风、遮光及光照阈值效果仍需装配和板测。

## 需要解决的问题

1. 阻塞步进动作不能占用 UI 或采集线程。两个执行器独立工作线程，各最多一条未完成命令；不堆积相对步数。
2. 明确保持、手动、自动模式。手动动作覆盖自动目标；返回自动必须显式操作。启动保持，不自动移动。
3. 温湿度或光照无效时暂停对应自动命令；已有动作不伪装为已取消。新目标合并为最新目标，实际调度在前次动作完成后进行。
4. 步进没有位置传感器。必须由操作员确认关闭参考位，才建立软件步数估计并允许动作；任何动作失败都使估计失效。不能写成自动回零、到位检测或无丢步。
5. 光照自动动作有 30 秒最小完成间隔，防止阈值波动下反复来回；手动指令不受该间隔限制。默认全行程 2048 半步仅为示例，需要按机构标定。
6. 输出请求、命令接受与物理动作分开。SG90 传播 PWM 配置错误；步进 ioctl 失败不得直接更新软件位置。

## 验证与停止

先运行不依赖 Qt 的策略、参考位、失败失效、重复命令和慢动作隔离测试，再验证 Qt 模拟流程、Linux 后端和模块编译。源码/产物哈希、命令和失败轮次存 `evidence/2026-11-17-actuator-restore/`。

本轮不连接真板或自动加载模块。真实 read/ioctl 不返回时仍不能保证退出期限。正常退出等待已开始动作返回，丢弃未开始任务；若曾使用舵机，随后请求停用 PWM，不强制转向某个未知机械安全角度。
