## 阶段与判据

1. 保存来源、环境及原始现象。Windows Qt 工具链必须通过编译、事件循环、按钮信号及渲染探针。

3. 每个周期采集独立调度，一次采集只尝试一次，下一周期重试。DHT11 不再在光照采集线程内等待 3 次 × 1.2 秒。通过可控慢采集主机替身验证隔离，记录光照更新间隔和退出耗时；不声称真板时间保证。
4. 构建 Windows Qt 模拟主程序并运行自动化操作流程；构建 Linux 后端。测试必须明确标为模拟，Windows 真设备模式明确拒绝。

## 报警行为

- 启动默认撤防。布防仅决定是否允许自动声音报警；温湿度超限和设备故障仍可亮灯提示。
- 活动报警 = 布防且 PIR 当前已知高电平。持续高电平不产生新报警代次；低电平恢复后再次变高才是新代次。
- 环境超限：温度 >=30℃ 或湿度 >=75% 置位；有效样本的温度 <=28℃ 且湿度 <=70% 才解除。回差用于减少阈值附近反复切换，不代表实测控制效果。
- 数据失败立即标记无效；成功值保留供查看时间和来源。超过有效期标记过期。失效不能自动解除上一次已知超限。
- 故障仅亮灯提示，不自动鸣叫。超限/活动报警在布防且未静音时允许蜂鸣。撤防立即取消自动蜂鸣；静音仅覆盖当前报警组合，新原因出现或清除后重触发会重新发声。
- PIR 为事件型输入，不按“多久没有边沿”判过期；连接或读取失败独立报告故障。高低电平事件可能合并，主程序不宣称逐边沿事件无损。
- 输出命令与输出接口成功状态分别显示。接口成功不等于物理 LED/蜂鸣器动作已经测得。
