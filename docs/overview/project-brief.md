# 场景、问题与设计取舍

## 定位

室内环境辅助控制与离场布防终端：在具备自然通风条件的小型固定室内空间，读取温湿度/光照、请求风门及采光/隐私帘动作，并在人工布防后监听 PIR 活动。轻型机构是匹配现有 SG90、28BYJ48 的应用假设，尚未装配验证。历史视觉、远端考勤与超声波不属于当前主程序。

范围收敛依据是业务依赖与验证成本。当前场景不要求身份识别或远端考勤，因此主程序移除图像处理、网络服务与数据库依赖；没有测量依据时，不将依赖减少换算成 CPU、功耗或可靠性提升。

| 链路 | 条件与行为 | 不能据此声称 |
|---|---|---|
| DHT11 → SG90 风门 | 主动选择自动；有效温湿度超限开、达到解除回差关 | 舵机产生风力、打开必然降温除湿、机械到位 |
| AP3216C → 28BYJ48 帘体 | 人工确认参考位、光照测量不受帘体显著遮挡；亮时开采光、暗时关保护隐私 | 已验证防晒/节能、自动回零、无丢步或堵转检测 |
| HC-SR505 → 声光活动提醒 | 人员主动离场布防，高电平触发；撤防不因活动蜂鸣 | 识别人、LOW 证明无人、自动判离场、现场误报率 |

PIR 对前两条环境控制链没有必要性。保留它的理由是独立的离场活动提醒需求；如果应用只需要环境辅助控制，该分支可以不启用，不能为使用已有器件而让它驱动电机。当前程序没有自动在场判断。

## 一个传感器失败拖慢其他采集

原整机顺序执行 DHT11、光照和测距，DHT11 三次失败的重试等待本身累计 3.6 秒。新实现按输入分别调度，一次执行一次测量，下一周期再试；数据记录最近成功、最近尝试和有效状态。

少量独立线程用于隔离阻塞接口，代价是线程及停止协调。主机闸门测试确认 DHT 进入阻塞后，光照仍取得额外四个成功样本。它证明代码的调度隔离，不代表 ARM 实测响应时间或单核吞吐提升。

## 报警、故障与旧数据分别处理

业务核心区分布防、活动、环境超限、设备故障、静音和有效期。温湿度用回差减少阈值附近反复切换；读取失败不解除旧超限；撤防取消自动声音，故障本身只亮灯。

策略通过状态序列与模拟界面测试。未进行现场误漏报评价；PIR 不提供身份或精确在场结论。输出请求、写接口结果和物理动作分别计账。

## 驱动与用户态等待契约

基准用户态通过 poll 等待，而旧 HC-SR505 没有 .poll。新驱动增加等待队列就绪通知、初始电平快照与单读取者约束；应用使用非阻塞 read 和有界 poll，契约不匹配时报告错误并退避。

退出仍依赖内核调用返回。工作线程能够回收的主机替身测试，不证明内核挂死时的退出期限。驱动在 5.4 x86_64 头文件下编译，旧 BSP 与实际 GPIO 行为待验证。

## 阻塞电机、手动接管与位置不确定性

已有步进驱动用休眠循环执行相对步数，全程 ioctl 结束才返回，2048 拍需要数秒。若直接在界面/采集槽中调用，控制与刷新都会等待。本轮用两个按需唤醒的电机线程隔离，各只允许一条未完成命令；忙时保留最新目标，前次完成后重新计算差值，避免积压一串过时的相对动作。单核上这是阻塞隔离，不能解释为计算加速。

启动保持；人工操作进入持续手动模式，读数变化不会覆盖；输入失败/过期暂停对应新自动动作，已经开始的动作不伪装为可取消。回差与帘体 30 秒完成间隔约束反复动作。代价是两个线程和模式/退出协调；参数仍需按场景标定。

步进没有限位或编码器，只能从人工确认的关闭位建立估计；失败后禁止盲目重试并使参考位失效。驱动部分执行后的错误改为 EINTR，避免信号重启路径重新执行相对步数。SG90 则取消 probe 自动居中，传播 PWM 错误，退出可显式停用 PWM。这些改动解决的是命令契约与未知状态处理，不增加物理反馈能力。

可量化的当前证据是：在同一闸门替身测试中，确认步进已阻塞后，光照新增 4 次更新，舵机命令完成，第二条步进命令被拒绝；状态测试覆盖失效暂停、手动接管、参考位失效和 30 秒调度门槛。它们是测试判据和主机观察，没有板端优化百分比，也没有通风/隐私收益的现场对照数据。

## 当前成果和边界

当前成果包括可测试的 C++ 核心、Windows Qt 模拟入口、Linux 后端、采集/动作隔离、数据有效期、报警生命周期和开环执行器失效处理。Windows 六项 CTest、Linux 11 个核心场景及 sanitizer 检查通过；目标板部署、采样质量、机构行程/负载、物理响应和长期指标尚未确认。
